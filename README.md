# Hixon Slope WCU – 3D Model (web viewer)

Static three.js viewer for GitHub Pages. Open index.html via the Pages URL (not from the file system).

- One finger: orbit · two fingers: pan · pinch: zoom · double-tap: new orbit centre · Reset view button
- Model: 15 GLB parts in m/ (meshopt-compressed geometry, KTX2/ETC1S 4096x4096 textures), ~51 MB total
- Libraries: three.js r169 (vendored in lib/)
